SAMPLE METHOD
Rows are selected at deterministic, evenly spaced positions across the
versioned full release. This exposes the real schema and representative
historical coverage without claiming to be a statistically random sample.

SECURITY
This archive contains data and documentation only: CSV, JSON and TXT.
It contains no executable files, scripts, macros or spreadsheet workbooks.
The build fails if a sampled cell looks like a spreadsheet formula. Verify
file integrity with SHA-256 before use.

LIMITATIONS
The sample supports schema evaluation and method execution. Because it is not
the complete study population, statistics calculated from it should not be
presented as reproductions of complete-release research. Null values are
expected. Post-transaction return fields are descriptive and do not establish
causation or predict future performance. Review the full methodology at:
https://insider-alpha.com/documentation
